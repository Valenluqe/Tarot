# The Fool — 3D

Standalone three.js scene (three@0.184 via import map) of the Tarot "The Fool" card.

- `index.html` — scene definition (was `The Fool.html`)
- `three-d-stage.js` — viewer shell: orbit controls, lighting, OBJ/GLB export buttons

Serve over HTTP (e.g. `python3 -m http.server`) and open `index.html`. Requires network access to unpkg.com for three.js.
